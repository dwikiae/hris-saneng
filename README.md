# HRIS PT Saneng

Monorepo HRIS internal PT Saneng.

## Struktur

- `backend/` - Laravel 11 API dan business logic.
- `frontend-hris/` - Next.js 14 portal internal HRIS.
- `frontend-web/` - Next.js 14 website publik.
